# Mizlish — Your Business AI Partner

An AI-powered business assistant for Indian SMEs. Handle sales, expenses, invoices, quotations, inventory, balance sheets, Tally exports, auditor workflows, and bank statement → ITR filing — all from a single app.

## How to view this app

### Option 1: Download and open
1. Download `index.html`
2. Double-click to open in any browser (Chrome, Firefox, Edge, Safari)
3. The app runs fully offline — no installation needed

### Option 2: GitHub Pages (live website)
1. Go to repo **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **`main`** → folder: **`/root`**
4. Click **Save**
5. Wait 30 seconds
6. Your app goes live at `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`

The app opens automatically because it's named `index.html` — GitHub Pages serves this as the default page.

## Features

- **AI Assistant** — Create invoices by typing natural language
- **Sales, Expenses, Invoices, Quotations** — Full business tracking
- **Inventory** — Stock alerts and margin analysis
- **Customer CRM** — GSTIN validation
- **Balance Sheet** — Monthly & yearly P&L statements
- **Tally Export** — CSV, XML, journal entries, master data
- **Auditor Kit** — 5-step workflow with WhatsApp/Email sharing
- **Bank Statement → ITR** — Upload CSV, auto-categorize, generate ITR balance sheet
- **Reports & Charts** — Chart.js powered analytics
- **Currency Converter** — Live rates via Frankfurter API
